Context is rent

Alex Lennon · @embedded_iot

Every always-on rule, skill description and tool server is paid on every turn. Measure the rent, then cut what no longer earns it.

Every always-on rule, fat skill, and optional tool server is paid on every turn. That’s not a metaphor — it’s the invoice.

We keep a lean core (memory, decisions, app control, a small durable runtime layer) and enable specialty tools only for the job. When the job ends, unload. No “leave it on in case”. Reloading the window is cheaper than carrying last week’s AppSec server forever.

If a session feels heavy, that’s a bug. Measure it. Cut it. The working relationship stays useful when the rent stays boring.
