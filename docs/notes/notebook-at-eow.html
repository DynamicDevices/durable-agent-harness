We update this at EOW

Alex Lennon · @embedded_iot

The notebook changes during evidence-led end-of-week review: publish what the week earned, and skip when it earned nothing.

How often should a public notebook move? Daily posts are vanity. Never is rot.

We’ll update chopwoodcarrywater.uk in the end-of-week review — the same Hansei pass where patterns get keep / amend / retire. If the week earned a note, a pack tweak, or a pattern change, it ships then. If not, we skip. No filler calendar.

That’s the cadence: weekly with the review, not whenever a chat feels productive.
