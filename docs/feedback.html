Help improve a guide

Reviewed 15th October 2026.

If a guide leaves you stuck, a short account of the step you tried helps us improve it. Suggestions and corrections are welcome too.

Use the existing repository issue route if you already use GitHub. You can also use Alex’s public @embedded_iot profile, linked from this notebook. There is no need to create an account for this guide; use a route you already have access to.

What helps

Copy the outline below into your message and fill in what you know. You do not need to include a project archive or complete transcript.

Host and version (Codex/Cursor, OS, Node if relevant):
Exact step or command:
Expected result:
Actual result (short error extract if useful):
Guide URL and heading, or file/line reference:
Pack/version reference (ZIP checksum or repository commit, if known):

Leave out secrets and private project or customer details. A small made-up example is often enough to reproduce a problem. GitHub issues are public; use the outline in whichever contact route you choose. Missing version details are fine.
