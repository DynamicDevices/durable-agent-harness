Measure

Felt speed is not a metric

We track tenure and capability. We refuse a marketing “N× more productive” number without a method.

What we count

  • Calendar tenure on the three clocks
  • Harness growth (skills / patterns) as investment
  • Outcomes that moved from impossible or uneconomic to routine
  • Proof-backed delivery — not lines of code

What we will not claim

  • A universal speedup versus every developer class
  • That agentic IDEs always win on familiar tickets (see METR 2025)
  • That more generated text equals more engineering
  • Anything that requires exposing private work to “prove” it
