# Contributing

This is a public lab note. Improvements to clarity, accessibility, and the
privacy gate are welcome.

1. Keep [`PRIVACY.md`](PRIVACY.md) — do not add private or competitive detail.
2. Edit `content/*.json` (source of truth), then run `npm run sync`.
3. Run `npm test` (privacy + Playwright) before opening a PR.
4. Say if a change was AI-assisted.

Issues are preferred for narrative debates; PRs for concrete site/content fixes.
